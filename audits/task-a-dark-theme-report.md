## Часть 1. Задача A — тёмная тема

### Что сделано

**Переменные.** В `main.css` заведены `--shadow-color`, `--shadow-accent-color`, `--danger`, `--text-muted`, `--text-faint`, `--surface`, `--surface-alt`, `--header-bg`, `--header-bg-solid`, `--on-ink`, `--on-accent`, `--ink-hover`, `--shadow-featured`, `--panel-*` (инвертированные панели), `--cta-*` (финальный CTA), `--art-*` (клиентский арт), `--glow-*`, `--deck-*`, `--slide-*`. Все зашитые цвета вне `:root`/`[data-theme]`/`@media print` устранены — проверено скриптом: **0 hex и 0 rgba вне блоков переменных** (кроме `@font-face`, где цветов нет).

**Две темы.** Светлая — по умолчанию, значения не изменились (эталон сохранён). Тёмная — `[data-theme='dark']` переопределяет всю цветовую карту. Акцент в тёмной теме — осветлённый `#a594ff` / `#8e77ff`, `--accent-soft` — тёмный тон `#27214a`. Контрасты тёмной темы (вычислено):

| Пара | Контраст |
|---|---|
| текст `--ink` / фон | 17.3:1 |
| `--text-muted` / фон | 10.9:1 |
| `--text-faint` / карточка | 5.4:1 |
| акцент / фон | 7.7:1 |
| `--on-accent` / акцент | 7.5:1 |
| `--accent-ink` / `--accent-soft` | 9.2:1 |
| панельный текст / панель | 16.4:1 |

Всё ≥ 4.5:1 для текста; границы и крупный текст — ≥ 3:1.

**Переключатель.** Кнопка `.theme-toggle` (солнце/луна, inline SVG, `aria-label="Переключить тему"`) на всех 4 страницах: шапка лендинга, шапки инвест-доков, хром презентации. Хранение — `localStorage['briix-theme']`; при пустом значении — `prefers-color-scheme`. Системная смена схемы подхватывается, пока пользователь не выбрал тему сам.

**Без мигания.** Инлайновый `<script>` в `<head>` **до** `<link>` на CSS ставит `document.documentElement.dataset.theme` — проверено на всех 4 страницах (скрипт: строка 16–18, CSS: 27–29).

**Мета-теги.** `<meta name="color-scheme" content="light dark">` + два `<meta name="theme-color">` с `media="(prefers-color-scheme: …)"` — на всех страницах.

**Печать.** `@media print` принудительно возвращает светлые токены (включая `--slide-*`) — PDF презентации будет светлым независимо от активной темы; `print-color-adjust: exact`.

**Демо-посты остаются светлыми.** Токены `--art-*` (артефакты клиента: канвасы постов, мокапы «сайта», checkerboard Designer) не переопределяются в тёмной теме и в печати.

**Инлайновые цветы в JS устранены:**
- `landing.js`: мобильное меню переведено на класс `.nav.open` (вместо `nav.style.background='#fff'`); ошибка ввода — класс `.url-input-wrap.error` (вместо `borderColor='#c2410c'`); цвета блобов перенесены в генератор палитры `paletteFor()`. Остальные литералы — авторская палитра демо-брендов (допустимо как «генерируемая палитра демо»).
- `finmodel.js`: цвет MRR — классы `.up`/`.down` вместо inline-стиля.

### Критерии приёмки

- [x] Обе темы переключаются на всех 4 страницах и сохраняются после перезагрузки
- [x] Нет мигания светлой темы при загрузке
- [x] В `main.css` вне блоков переменных не осталось зашитых цветов
- [x] В `landing.js` не осталось зашитых цветов, кроме палитры демо
- [x] Тёмная тема применяется через `prefers-color-scheme`, если выбора нет
- [x] `@media print` отдаёт светлую тему
- [x] Контраст текста в тёмной теме ≥ 4.5:1 (см. таблицу выше)
- [x] Светлая тема не сломалась: значения токенов совпадают с исходными

### Что осталось непроверенным

- Визуальная сверка «пиксель в пиксель» светлой темы с деплоем — нет растрового эталона; сверка выполнена по значениям токенов (все исходные hex/rgba сохранены).
- Проверка на реальных устройствах (iOS Safari `backdrop-filter`, старый Safari `conic-gradient`) — без физических устройств.
- Презентация: в светлой теме слайды получили светлую палитру (`--slide-*`), в тёмной — исходный тёмный вид. Это осознанное решение под требование «светлый PDF»: тема на странице презентации переключает слайды целиком.

## Часть 2. Доработки от основателя

### 1. Реальный контент для демо

`assets/js/landing.js` — три полностью прописанных демо-бренда (6 постов в каждом):
- **nordhavn-studio.com** — архитектурная студия (Берген);
- **vela-clinic.com** — стоматология (без обещаний лечения, с модерационной безопасностью);
- **lumina-skin.com** — уходовая косметика.

У каждого поста: заголовок, арт-заголовок, полный текст для ленты, **адаптации для деловой сети и канала**, хэштеги, CTA, рубрика. Для произвольного домена — персонализированный generic-набор с подстановкой имени бренда.

Новое: **модалка поста** (клик по любой карточке в демо) — крупный визуал, вкладки «Лента / Деловая сеть / Канал» с переключением вариантов текста, хэштеги, CTA, кнопки «Одобрить / Править в чате / Designer». Плюс тизер контент-плана («50+ идей, ещё 44 в очереди»).

### 2. Блок «5 ловушек» переработан

- Заголовок секции: «Пять причин, почему соцсети бизнеса „не идут“» — понятно без контекста.
- Последняя карточка: «Что происходит дальше» вместо «Пока вы паузуете».
- Блок-резюме: «BRIIX снимает всё это — с одной ссылки на ваш сайт» + самодостаточный текст без отсылок к «ловушкам».
