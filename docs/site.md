# BRIIX — сайт проекта (лендинг + презентация + инвест-разделы)

Статический сайт без сборки: открывается любым статик-хостингом (GitHub Pages, Netlify, nginx, `python -m http.server`).

Опубликован: **https://rucorp.github.io/briix/** — ветка `main`, корень репозитория, все пути внутри относительные.

## Структура

| Файл | Назначение | Видимость |
|---|---|---|
| `index.html` | Продуктовый лендинг BRIIX | **Публичный** |
| `presentation.html` | Презентация проекта (20 слайдов, клавиши ← →, печать в PDF) | **Только по прямой ссылке** |
| `investors/index.html` | Раздел для инвесторов: резюме, экономика, план, риски, раунд | **Только по прямой ссылке** |
| `fin-model/index.html` | Финансовая модель + интерактивный калькулятор юнит-экономики | **Только по прямой ссылке** |
| `assets/` | CSS, JS, шрифты, графика | — |

## Скрытые разделы

Страницы `presentation.html`, `investors/` и `fin-model/`:

- **не имеют ни одной ссылки** на них в публичном лендинге (`index.html`);
- помечены `<meta name="robots" content="noindex, nofollow">`;
- закрыты в `robots.txt`;
- ссылаются друг на друга и на лендинг.

Доступ — только по прямым URL:

```
/presentation.html
/investors/
/fin-model/
```

> Примечание: это «unlisted»-доступ (кто знает ссылку — тот открывает), как и просили. Если понадобится жёсткая защита — страницы выносятся за базовую аутентификацию на уровне хостинга.

## Локальный запуск

```bash
git clone https://github.com/rucorp/briix.git && cd briix
python3 -m http.server 8080
# → http://localhost:8080
```

## Дизайн-система

- Тёплая нейтральная база (`#FAF7F2`) + один акцент (`#5338F2`) — продукт не «красит» клиентские палитры в себя.
- Шрифты: Manrope (заголовки) + Inter (текст), self-hosted, с кириллицей.
- Интерактивное демо на лендинге имитирует продуктовый поток «URL → Brand DNA → 6 постов»; палитра демо выводится из домена (хэш) — каждый запуск персонален.
- Вся графика интерфейса — нативные HTML/CSS-мокапы (чёткий текст, редактируемость, без растровых подделок).

## Правки контента

Цифры модели (тарифы, ARPA, LTV/CAC, сценарии, P&L) взяты из канона `docs/BRIIX.md` и `docs/source/Native.txt`. При изменении модели обновите: слайды 10–13 презентации, разделы `investors/` и таблицы `fin-model/`.
