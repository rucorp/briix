# BRIIX — документация проекта

Единая точка входа в документацию проекта **BRIIX** — SaaS-сервиса автоматизации SMM для малого бизнеса («AI-маркетолог по URL сайта»).

## Основной документ

- **[BRIIX.md](./BRIIX.md)** — базовый документ начала проекта. Канонический синтез трёх исходных версий: суть и позиционирование, проблема и ценность, ЦА и персоны, видение, core user flow, функции и границы MVP, Designer, каналы и интеграции, монетизация, автоматизация и feedback loop, риски, архитектурные намёки, границы MVP и следующие шаги.

## Исходные материалы

Папка [`source/`](./source/) содержит три исходные версии, из которых собран канон:

| Файл | Роль |
|---|---|
| [`source/Native.txt`](./source/Native.txt) | Основной источник — детальное ТЗ (FR, UC, пайплайны, финмодель, инфраструктура, риски) |
| [`source/project2.txt`](./source/project2.txt) | Мастер-спека для агентов сборки (стек, ADR, Prisma-модель, очереди, правила агентов) |
| [`source/PROJECT.md`](./source/PROJECT.md) | MVP-спека для агента-исполнителя (интерфейс AIProvider, API-контракты, build order, DoD) |

> При расхождениях между версиями действует канон раздела 4.4 основного документа.

## Аудиты и ревью

Папка [`../audits/`](../audits/) — следы аудитов, ревью и контрольных проверок (в т.ч. от агентов-ревьюеров).

## Статус

Стадия: **старт проекта**. Канон зафиксирован, репозиторий инициализирован, критические решения по архитектуре (DesignDoc, Brand DNA pipeline) — следующий шаг.
