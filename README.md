# BRIIX

> AI-маркетолог по URL сайта — SaaS-платформа автоматизации SMM для малого бизнеса.

**BRIIX** изучает сайт компании, собирает профиль бренда (Brand DNA), генерирует план контента, создаёт посты (текст + визуал) в фирменном стиле, публикует их по расписанию в соцсетях и собирает аналитику — при нулевом усилии на входе.

## Структура репозитория

Корень репозитория — статический сайт, он же публикуется на GitHub Pages. Документация лежит в `docs/`.

```
index.html         — продуктовый лендинг (публичный)
presentation.html  — презентация проекта, 20 слайдов (по прямой ссылке)
investors/         — раздел для инвесторов (по прямой ссылке)
fin-model/         — финансовая модель и калькулятор юнит-экономики (по прямой ссылке)
assets/            — CSS, JS, шрифты, графика
docs/              — вся документация проекта (канон + исходники)
audits/            — аудиты, ревью и контрольные проверки
```

- **[docs/BRIIX.md](./docs/BRIIX.md)** — базовый документ начала проекта (канонический синтез трёх версий).
- **[docs/README.md](./docs/README.md)** — индекс документации.
- **[docs/site.md](./docs/site.md)** — устройство сайта и дизайн-система.
- **[audits/](./audits/)** — следы аудитов и ревью.

## Сайт

Опубликован на GitHub Pages: **https://rucorp.github.io/briix/**

| Раздел | URL | Видимость |
|---|---|---|
| Лендинг | `/` | публичный |
| Презентация | `/presentation.html` | по прямой ссылке |
| Инвесторам | `/investors/` | по прямой ссылке |
| Финмодель | `/fin-model/` | по прямой ссылке |

Скрытые разделы помечены `noindex` и закрыты в `robots.txt`, но это «unlisted»-доступ — кто знает ссылку, тот откроет. При появлении домена страницы переезжают без изменений.
