# BRIIX

> AI-маркетолог по URL сайта — SaaS-платформа автоматизации SMM для малого бизнеса.

**BRIIX** изучает сайт компании, собирает профиль бренда (Brand DNA), генерирует план контента, создаёт посты (текст + визуал) в фирменном стиле, публикует их по расписанию в соцсетях и собирает аналитику — при нулевом усилии на входе.

## Структура репозитория

```
docs/     — вся документация проекта (канон + исходники)
audits/   — аудиты, ревью и контрольные проверки
```

- **[docs/BRIIX.md](./docs/BRIIX.md)** — базовый документ начала проекта (канонический синтез трёх версий).
- **[docs/README.md](./docs/README.md)** — индекс документации.
- **[audits/](./audits/)** — следы аудитов и ревью.

## Статус

Старт проекта. Канон зафиксирован. Следующий шаг — проектирование рисковых узлов (JSON-схема `DesignDoc`, Brand DNA pipeline) и запуск критического пути согласований.
