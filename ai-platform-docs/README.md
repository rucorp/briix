# Документация платформы ИИ — рабочая версия

**Статус:** проектный черновик, 5 ноября 2026. Это базовый комплект для обсуждения и оценки; неизвестные параметры отмечены как TBD и не считаются принятыми решениями.

Платформа — веб-сервис и OpenAI-совместимый API-шлюз. Сначала разворачивается с тестовым адаптером и одним inference backend. Кандидаты: локальная модель в собственном ЦОД и/или модели/вычислительные ресурсы Yandex Cloud. Yandex Cloud — облачный backend, не собственный локальный ЦОД; конкретный сервис и права использования требуют проверки. Основные группы клиентов: российские юрлица с оплатой в рублях и разработчики/пользователи, которым нужен единый ключ для нескольких моделей. Веб-чат — следующий этап привлечения, не блокирующий запуск API.

## Принятые рабочие предположения

1. Первый коммерческий продукт — API, а не чат.
2. Один ключ, выпущенный платформой, работает с разрешёнными моделями каталога; ключи поставщиков клиенту не выдаются.
3. На старте используется детерминированный тестовый адаптер и один inference backend. Кандидаты: собственный ЦОД и/или Yandex Cloud. Yandex Cloud — облачный backend, не собственный локальный ЦОД; конкретная услуга и права использования требуют проверки.
4. Основной интерфейс — веб-приложение. Мобильная адаптация обязательна, отдельные нативные приложения не входят в MVP.
5. Нет внешнего входа через Google/Apple/соцсети. Рекомендуемый MVP-вариант — email + пароль; email используется для подтверждения и восстановления. PIN на экранной клавиатуре не используется как единственный способ входа.
6. Чат с ограниченной бесплатной квотой — следующий этап, использующий тот же API-шлюз, но с отдельными лимитами.
7. Стек, характеристики ЦОД, модельный список, цены, сроки хранения данных и юридическая схема пока не заданы.

## Как вести документацию

Изменения продуктовых решений фиксировать в `DECISIONS.md` (создаётся при первом архитектурном решении) с датой, причиной, альтернативами и последствиями. Не подставлять выдуманные модели, тарифы, SLA или юридические обещания. TBD необходимо закрыть до соответствующего релиза.
