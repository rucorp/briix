# Текущее состояние проекта — по словам команды

**Статус:** исходные сведения пользователя, не технический аудит. 5 ноября 2026.

## Подтверждено командой

- У команды есть собственный небольшой ЦОД.
- Команда настраивала локальные модели и работу с собственным ЦОД.
- У команды уже есть шлюз для доступа к моделям платформ.
- Команда сравнивает самый дешёвый вариант запуска; Yandex Cloud рассматривается как потенциально более дешёвый старт, чем локальная модель на собственном оборудовании.
- Целевой продукт — веб-платформа и OpenAI-совместимый API с единым ключом; чат — возможный следующий этап.

## Ещё не подтверждено / необходимо проверить

- Какие модели, адаптеры, контракты и возможности уже работают в шлюзе.
- Пропускная способность, надёжность, мониторинг, безопасность, metering и готовность шлюза к многопользовательской эксплуатации.
- Характеристики серверов и фактическая переменная/полная стоимость ЦОД.
- Что именно команда называет вариантом Yandex Cloud: управляемый API модели или собственный inference на облачных вычислительных ресурсах.
- Актуальная стоимость, квоты, регион, качество и права выбранного Yandex Cloud сценария на перепродажу/проксирование.

## Следующий рабочий шаг

Не переписывать существующий шлюз до аудита. Сначала заполнить инвентаризацию текущего решения и провести сравнение затрат по [COST_MODEL.md](COST_MODEL.md). После этого документация должна описывать целевую платформу с учётом того, что уже реализовано, а не считать её greenfield.
